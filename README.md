# AYK+

Kişisel beslenme, antrenman ve mobilite takip uygulaması (iPhone için PWA). GitHub Pages üzerinden yayınlanır.

- Canlı uygulama: bu deponun GitHub Pages adresi (index.html)
- Geliştirme: `src/` altındaki dosyalar düzenlenir, `npm run build` ile `index.html` üretilir.
- Test: `npm test`
- Ayrıntılı rehber: [CLAUDE.md](CLAUDE.md)
